# Vishal Srivastava - Portfolio Website

A modern, interactive portfolio website built with Angular showcasing work experience, projects, and professional skills.

## Features

- **Responsive Design**: Mobile-first approach with seamless experience across all devices
- **Interactive Navigation**: Smooth navigation with active link indicators
- **Animated Components**: Engaging animations and transitions throughout the site
- **Projects Showcase**: Featured and regular project cards with technology stacks
- **Work Timeline**: Expandable work experience timeline with detailed descriptions
- **Skills Display**: Organized skill categories with interactive elements
- **About Section**: Personal introduction with professional journey and contact options
- **Modern Styling**: Gradient backgrounds, shadows, and modern UI elements

## Pages

1. **Home** - Landing page with intro, typing effect, and tech stack preview
2. **Experience** - Interactive timeline of work history with expandable details
3. **Projects** - Showcase of featured and other projects with live demos and source code links
4. **About** - Personal background, comprehensive skills, and contact information

## Tech Stack

- **Frontend Framework**: Angular 17
- **Styling**: CSS3 with gradients and animations
- **Animations**: Angular animations
- **Routing**: Angular Router
- **Standalone Components**: Modern Angular components

## Installation

```bash
# Clone the repository
git clone https://github.com/yourusername/portfolio-website.git

# Navigate to project directory
cd portfolio-website

# Install dependencies
npm install
```

## Development

```bash
# Start development server
npm start

# Open browser and navigate to
http://localhost:4200
```

The application will automatically reload on code changes.

## Building for Production

```bash
# Build for production
npm run build

# Output will be in dist/portfolio-website/
```

## Customization

### Update Personal Information
- Edit component templates to add your information
- Update social links in the footer
- Modify project details and links

### Styling
- Main colors defined in component CSS files
- Global styles in `src/styles.css`
- Responsive breakpoints at 768px

### Add Resume PDF
- Place resume in `/src/assets/` folder
- Update download link in home component
